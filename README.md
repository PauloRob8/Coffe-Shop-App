### How to use

Inside the home page tap on the left buttons to filter the items. Tap on a item to go the *add to cart screen* that you cange your preferences such as flavor, topping and size. After that you can see your item on the Cart screen and make a checkout.


### Info

In this app is used the flutter_bloc, and cubbit for state management.

In the test folder have some BloC and widgets test.

The coffeshopapp.apk can be used for testing on android devices.
